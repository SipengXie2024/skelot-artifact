# Reference results

Every file here is an output of a run described in the artifact README, kept so
that the analysis and figure scripts can be checked without first spending the
17 hours a full Base reproduction costs. The scripts read `results/` first and
fall back to this directory, so a fresh run of a measurement automatically takes
precedence over the copy shipped here.

All of it is at the current skeleton boundary (strip PUSH immediates, the
Solidity CBOR metadata trailer, and trailing zeros) unless a line below says
otherwise. Older results at the previous boundary are deliberately not shipped;
mixing the two produces numbers that appear in no version of the paper.

## Logs

`logs/` holds the run logs from the measurement campaign. For most steps the
log's launch timestamp and its modification time are the only wall-clock record,
which is why the README quotes durations to the nearest minute rather than
claiming an internal timer. The paired replay log `paired_emse_base_sampled100_20260909T065454Z.log` carries a
toolchain banner and `/usr/bin/time -v` output.

## Two files that are deliberately not shipped

| File | Size | Why not |
|---|---|---|
| `skeleton_registry_full_emse_forced.bin` | 551,704,094 bytes, sha256 `12f867c5fb71f82995aaa222b704d5952d8a3f13023971c34e435ed54214112b` | This is the all-variant registry.
